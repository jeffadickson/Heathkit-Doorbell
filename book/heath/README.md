# Heath Company material

Schematic of the Heathkit Programmable Electronic Chimes, Model TD-1089, Heath part 595-1826-05, © 1975 Heath Company. Included for reference and study of a discontinued product; not covered by this repository's licenses.

`schematic/` holds 800 × 455 captures of the sheet, taken from the archive scan (5949 × 3099 RGB):

| File | Region |
|---|---|
| `00-overview.jpg` | Whole sheet |
| `r1c1-front-latch-title.jpg` | Title block, front door input and latch |
| `r1c2-beat-buffer-decay.jpg` | Beat generator, buffer, decay circuit |
| `r1c3-audio.jpg` | Audio amplifier and speaker |
| `r2c1-rear-latch-counter.jpg` | Rear door latch, counter IC2 |
| `r2c2-decoder-ladder.jpg` | Decoder IC3, beat diodes, top of the note ladder |
| `r2c3-tone-osc-power.jpg` | Tone oscillator, tuning pot, power supply |
| `r3c1-rear-reset.jpg` | Back door reset jumper |
| `r3c2-decoder-outputs-ladder.jpg` | Decoder outputs A1–A16, full note ladder |
| `r3c3-power-supply.jpg` | Power supply and transformer |
| `detail-decay-circuit.jpg` | Decay circuit close-up |
| `detail-beat-generator.jpg` | Beat generator close-up |

The full PDF (`td1089-schematic.pdf`, 5,320,621 bytes) is pinned by SHA-256 in `src/td1089.json`. `make schematic` downloads it and checks the hash.
